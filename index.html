    About AirWatch India

    What is this?

    AirWatch India is an educational data science project that analyses daily air quality measurements from 26 Indian cities between 2015 and 2020. It uses Python, pandas, scikit-learn, SQLite, and Flask on the backend, with plain HTML/CSS/JavaScript on the frontend.

    AQI Scale (India CPCB)

    0–50 Good
    51–100 Satisfactory
    101–200 Moderate
    201–300 Poor
    301–400 Very Poor
    401–500 Severe
    >500 Severe+

    Data Source

    Dataset: Air Quality Data in India — Kaggle

    Tech Stack

    • Python 3.13 · Flask 3.1 · pandas 2.3 · scikit-learn 1.7
    • SQLite (no server needed)
    • Chart.js 4.4 · Inter font · plain HTML + CSS
